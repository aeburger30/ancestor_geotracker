Open any ancestor's FamilySearch Person Details page in Chrome, open the Gemini side panel, and paste this prompt. Then paste Gemini's JSON output below:

Extract all genealogical data visible on this FamilySearch Person page (including the main person, their spouses, parents, or children if shown, and all Vitals / Events / Sources / Memories places & dates) into a single valid JSON object for Ancestor GeoTracker.

Return ONLY raw JSON (no markdown commentary) matching this exact schema:
{
  "persons": [
    {
      "id": "p_KWJ1-001",
      "name": "Full Name",
      "fsId": "KWJ1-001",
      "birthYear": 1808,
      "deathYear": 1878,
      "branchColor": "#38bdf8"
    }
  ],
  "relationships": [
    {
      "id": "r_1",
      "person1Id": "p_KWJ1-001",
      "person2Id": "p_KWJ1-002",
      "type": "spouse"
    }
  ],
  "events": [
    {
      "id": "e_1",
      "personId": "p_KWJ1-001",

      "place": "Town, County, State, Country",

1. Always include accurate decimal latitude ("lat") and longitude ("lng") for every event place.
2. Use the person's FamilySearch ID (e.g. "KWJ1-001") in "fsId".
3. For "branchColor", use "#38bdf8" (sky blue), "#f43f5e" (rose), "#34d399" (emerald), "#a855f7" (purple), or "#fb923c" (orange).
